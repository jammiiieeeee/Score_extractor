GitHub Actions Cheat Sheet

Triggers

on:
  push:
    branches: [main]           # On push to main
  pull_request:
    branches: [main]           # On PR targeting main
  schedule:
    - cron: '0 2 * * 1'       # Every Monday at 2am UTC
  workflow_dispatch:            # Manual trigger (button in UI)

Runners

RunnerOSUse when
ubuntu-latestLinuxDefault choice (fastest)
windows-latestWindows ServerNeed Windows APIs (.exe, WinGet, COM)
macos-latestmacOSNeed macOS (Xcode, Swift)

Matrix Strategy

strategy:
  matrix:
    python-version: ["3.10", "3.12"]
    os: [ubuntu-latest, windows-latest]
  fail-fast: false  # Don't cancel other jobs on failure

Common Steps

# Checkout code
- uses: actions/checkout@v4

# Setup language
- uses: actions/setup-python@v5
  with:
    python-version: '3.12'

# Cache dependencies
- uses: actions/cache@v4
  with:
    path: ~\AppData\Local\pip\Cache
    key: ${{ runner.os }}-pip-${{ hashFiles('requirements.txt') }}

# Run commands
- run: |
    python -m pip install -r requirements.txt
    python -m pytest tests/

# Conditional
- if: matrix.python-version == '3.12'
  run: echo "Only on Python 3.12"

# Upload artifacts
- uses: actions/upload-artifact@v4
  with:
    name: my-report
    path: report.xml

Expression Syntax

ExpressionReturns
${{ matrix.python-version }}Current matrix value
${{ runner.os }}Windows / Linux / macOS
${{ hashFiles('requirements.txt') }}Hash of file contents
${{ github.event_name }}push / pull_request / etc.
${{ success() }}true if previous steps passed

Your Project's Markers

pytest -m "not slow"      # CI: skip slow tests (~45s)
pytest -m "slow"           # Local: run only slow tests
pytest -m "integration"    # Integration tests only
pytest                     # Everything (~370 tests)
