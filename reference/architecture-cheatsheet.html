Clean Architecture Layers

API Layer
Entry points: GUI, CLI, Web
↓
Application Layer
Use Cases: Business workflows
↓
Domain Layer
Business Rules: Models, Interfaces
↑
Infrastructure Layer
Implementations: External services

The 5 Rules of Clean Architecture

  1. Dependencies point inward - Outer layers depend on inner layers
  2. Domain has no dependencies - Only standard libraries allowed
  3. Use interfaces for abstraction - Define contracts in Domain layer
  4. Inject dependencies - Pass implementations, don't create them
  5. Keep layers thin - Outer layers mostly delegate to inner layers

API Layer (src/api/)

Purpose: User interaction

Contains:

  • GUI frameworks (PyQt6)
  • CLI argument parsing
  • HTTP endpoints

Depends on: Application layer

Application Layer (src/application/)

Purpose: Orchestrate workflows

Contains:

  • Use cases (business operations)
  • Workflow coordination
  • Data transformation

Depends on: Domain layer

Domain Layer (src/domain/)

Purpose: Business logic core

Contains:

  • Models (Frame, ScoreConfig)
  • Interfaces (IVideoService)
  • Business rules (deduplication)

Depends on: Nothing (except stdlib)

Infrastructure Layer (src/infrastructure/)

Purpose: External integrations

Contains:

  • OpenCV (video)
  • PaddleOCR (text recognition)
  • ReportLab (PDF generation)

Depends on: Domain interfaces
