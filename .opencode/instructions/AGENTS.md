# RULE: NEVER COMMIT WITHOUT EXPLICIT PERMISSION

**This rule is absolute. There are zero exceptions.**

- Wait for the user to say "commit", "commit this", or words to that effect.
- Suggesting a commit with "Want me to commit?" is fine. Actually doing it without a reply is not.
- After tests pass, do NOT automatically commit. Stop and ask.
- The only acceptable commit trigger is the user explicitly telling you to commit.
- If unsure whether the user wants a commit → do NOT commit. Ask first.

Violating this rule will result in the user being justifiably angry. Do not violate it.
